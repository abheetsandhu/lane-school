# Lane School

A mobile-friendly swim lesson booking prototype by Abheet Sandhu. Parents choose a lesson based on what their swimmer can already do, compare sample sessions and review their selection before confirming a demo booking.

## Run locally

Download the project and open `index.html` in a browser. The prototype uses plain HTML, CSS and JavaScript and runs offline.

## Try the flow

Choose a swimmer who is new to lessons. Find the available Saturday session, review the level and price, then switch to Sunday before confirming. The full session stays visible so families can see why it is unavailable.

All sessions and prices are examples. The demo collects no personal information and makes no real reservations.
